# روكن فاروق — ROKN FAROUQ

صفحة توثيقية عربية (RTL) عن الملك فاروق الأول، منفَّذة من تصميم Figma مشترك.

**Live demo:** https://lleoparden.github.io/rokn-farouq/ _(تُفعَّل بعد نشر الصفحة الأولى)_

## الفكرة
تحويل تصميم Figma (روكن فاروق — عن الملك فاروق، نسخ desktop/tablet/mobile) إلى موقع ثابت سريع:
عربي كامل، أخضر ملكي + كريمي + ذهبي، خطوط Amiri وAref Ruqaa، متجاوب 375/768/1280، بدون بناء (static).

## الأقسام
قاعة البطل (خلفية القصر + العنوان) — وثيقة عن الملك (صورة + عمودان) — حياة الملك (3 صور بيضاوية) — شجرة العائلة — لقطات من الأرشيف — تذييل.

## التقنية
HTML + CSS + JS فقط، لا اعتماديات. خطوط Google Fonts. تفاعلات: قائمة جوال، ظهور تدريجي، عارض صور، تمييز القسم النشط.

## ما تعلمته
النصوص العربية الملكية تحتاج تباينًا عاليًا على الأخضر الداكن؛ إطارات الصور المائلة تعطي إحساس الأرشيف دون صور ثقيلة؛ الـ lightbox البسيط أفضل من مكتبة.
